# Features

- **Library**: TitleDB metadata, covers, required firmware (read from CNMT), installed detection from the console inventory.
- **Import**: sort dumps into library folders; free space of each folder shown.
- **Send**: queue, space check against the chosen storage (SD/NAND), live progress with a storage map, history.
- **Console tab**: storage usage, installed titles, update from library, remote uninstall, save backups, captures gallery.
- **Cheats**: pushed to the console via SSI.
- **Remote management** (SSI option): lets SSM install without on-console confirmation during a session (sessions expire after 10 minutes).
- **Keep awake**: SSM prevents PC sleep during transfers; SSI can keep the console awake while charging.
- **Themes**: see [../themes/README.md](../themes/README.md).
