# Getting started

1. Download the latest release zip from [Releases](../../../releases) and check it against `SHA256SUMS`.
2. Unzip anywhere and start `Switch-Super-Manager.exe`.
3. Settings: add your library folder(s) and point to **your own `prod.keys`** (required, never provided).
4. Import your dumps in the Import tab.
5. On the console, install **Switch-Super-Installer** (`.nro` in `/switch/`) and launch it from the album (applet mode is not supported).
6. In SSM, Console tab: enter the console IP, then send titles from the library.

Both devices must be on the same LAN; see [network.md](network.md).
