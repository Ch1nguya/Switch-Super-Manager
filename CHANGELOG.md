# Changelog

## 0.6.0
- Console tab loads asynchronously with a cache; sub-tabs (storage, titles, saves, captures).
- Send queue, transfer history, free-space check, progress bar and detail window with storage map.
- Cheats delivery over SSI's HTTP server; remote uninstall; save backups; captures backup and gallery.
- Update console titles from the library.
- External user themes (`themes/<name>/theme.json`); built-in themes stay immutable.
- Remote management option in SSI (installs without confirmation during a session).
- Choice of install location (SD / NAND / ask each time).
- Keep-awake option (SSM and SSI).
- Free space of library folders in the Import tab.
- Icons on all buttons; dark overlay behind dialogs; many UI fixes.
